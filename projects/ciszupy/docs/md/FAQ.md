PREGUNTAS FRECUENTES / FREQUENTLY ASKED QUESTIONS

[ESPAÑOL]

P: ¿Cómo instalo Ciszupy?
R: Usa pip install ciszupy o pipx install ciszupy.

P: ¿Qué versiones de Python soporta?
R: Python 3.10 o superior.

P: ¿Cuántos comandos tiene?
R: Actualmente 5 comandos: help, helloworldmemetest, profesor, papa, mama.

P: ¿Necesita el paquete acceso a internet?
R: No. Ciszupy funciona completamente offline una vez instalado.

P: ¿Ciszupy almacena datos del usuario?
R: No. El paquete no guarda información personal.

P: ¿Puedo contribuir con nuevos comandos?
R: Sí, puedes sugerirlos en el servidor de Discord o en GitHub Issues.

[ENGLISH]

Q: How do I install Ciszupy?
A: Use pip install ciszupy or pipx install ciszupy.

Q: What Python versions does it support?
A: Python 3.10 or higher.

Q: How many commands does it have?
A: Currently 5 commands: help, helloworldmemetest, profesor, papa, mama.

Q: Does the package need internet access?
A: No. Ciszupy works completely offline once installed.

Q: Does Ciszupy store user data?
A: No. The package does not save personal information.

Q: Can I contribute new commands?
A: Yes, you can suggest them on the Discord server or GitHub Issues.
