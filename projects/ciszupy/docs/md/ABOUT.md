SOBRE CISZUPY / ABOUT CISZUPY

[ESPAÑOL]
Ciszupy es una librería y CLI de Python híbrida que invierte el clásico HelloWorld
y rinde homenaje a los seres queridos. Moderna, rápida y fácil de usar.

Desarrollada con Python 3.10+, Typer, Rich y Keyboard, Ciszupy ofrece una
experiencia interactiva en la terminal con comandos personalizados.

COMANDOS DISPONIBLES:

- Información: help, helloworldmemetest
- Homenajes: profesor, papa, mama

CARACTERÍSTICAS:

- CLI con Typer
- Salida enriquecida con Rich
- Hotkeys globales con Keyboard
- Auto-instalación de dependencias
- Clear screen automático

[ENGLISH]
Ciszupy is a hybrid Python library and CLI that inverts the classic HelloWorld
and pays tribute to loved ones. Modern, fast, and easy to use.

Built with Python 3.10+, Typer, Rich, and Keyboard, Ciszupy offers an
interactive terminal experience with custom commands.

AVAILABLE COMMANDS:

- Information: help, helloworldmemetest
- Tributes: profesor, papa, mama

FEATURES:

- Typer-based CLI
- Rich terminal output
- Global hotkeys with Keyboard
- Auto-install dependencies
- Auto clear screen
