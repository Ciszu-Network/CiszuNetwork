# CiszuPy

`ciszupy` es una herramienta híbrida de Python que combina una **CLI interactiva** y una **librería** moderna, construida con **Typer**, **Rich** y **Keyboard**. Invierte el clásico `HelloWorld` y rinde homenaje a los seres queridos a través de comandos personalizados.

---

## 📦 Instalación

```bash
pip install ciszupy
pipx install ciszupy
```

## 📋 Requisitos

- **Python**: `>=3.10`
- **Dependencias**:
  - `typer` — CLI moderna
  - `rich` — salida en consola con colores y estilos
  - `keyboard` — escucha de hotkeys globales

## 🚀 Uso

```bash
ciszupy --help
ciszupy profesor
ciszupy papa
ciszupy mama
ciszupy helloworldmemetest
```
