# Documentación oficial — MuzicMania

Esta carpeta (`documentation/`) contiene la **documentación oficial** del proyecto MuzicMania.

Hasta el 5 ago 2026 se llamaba `ia_docs/` y se trataba como documentación interna generada por agentes de IA. **A partir de ahora es documentación oficial por proyecto**: la mantiene el equipo (agentes + CEO), se revisa en commits como el resto del repo y es la fuente de verdad para decisiones, arquitectura, estándares y estado.

Reglas:
- Cambiar esta documentación = actualizar también las referencias cruzadas (paths, `docs/*.md`, scripts).
- No borrar secciones sin antes actualizar quien las referencia.
