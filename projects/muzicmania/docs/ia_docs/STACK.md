## 🧩 2. Extensiones Indispensables (VS Code / IDX)
### Desarrollo Web & Frameworks
- **Tailwind CSS IntelliSense**: Autocompletado, resaltado de sintaxis y preview de clases neón.
- **ES7+ React/Redux snippets**: Creación de componentes funcionales en segundos.
- **Auto Rename Tag**: Sincronización automática de etiquetas HTML/JSX.
- **Import Cost**: Visualización en tiempo real del peso de las librerías importadas.
- **Project Manager**: Acceso rápido entre el repo de la web, el bot y microservicios.

### Inteligencia, Datos & Backend
- **Prisma**: ORM visual para gestionar el esquema de base de datos de Supabase.
- **PostgreSQL Client**: Consultas SQL directas a la base de datos sin salir del editor.
- **Dutton Code**: Monitor de consumo de tokens para gestionar tus cuentas IA.
- **Thunder Client / Postman**: Testeo de API Routes y sistemas de autenticación.

### Calidad de Código & UI
- **ESLint & Prettier**: Garantía de código limpio y mantenimiento de encoding **UTF-8**.
- **GitLens**: Historial profundo de commits para rastrear la evolución de cada función.
- **Error Lens / Todo Tree**: Resaltado inmediato de errores y gestión de tareas pendientes.
- **SVG Previewer / Color Highlight**: Visualización de iconos y colores neón en el código.

## 🚀 3. Stack Tecnológico (Frameworks & Libraries)
### Frontend & Renderizado
- **Next.js 15+**: Motor principal para producción (App Router, SEO, Server Components).
- **React.js**: Biblioteca base para la creación de interfaces reactivas.
- **TanStack Query**: Gestión de caché y sincronización de datos de canciones/scores.
- **Zustand**: Manejo de estado global ligero (volumen, estado del juego, sesión).

### Estética & Experiencia
- **Tailwind CSS**: Estilizado mediante clases de utilidad para rapidez máxima.
- **Framer Motion**: Animaciones complejas, transiciones de página y efectos neón.
- **Shadcn/UI**: Set de componentes de alta calidad, accesibles y personalizables.
- **Howler.js**: Motor de audio de alta fidelidad con control de latencia para el ritmo.

### Backend, Auth & Realtime
- **Supabase**: Base de datos relacional (PostgreSQL), Storage de audios y Realtime.
- **Firebase**: Analíticas en tiempo real y backup de base de datos secundaria.
- **Clerk / Auth.js**: Alternativas de autenticación ultra-seguras con OAuth (Discord/Google).
- **Redis (Upstash)**: Almacenamiento en caché para leaderboards globales instantáneos.
