# CiszuAI — capa de IA del ecosistema

**CiszuAI** es el proyecto que habilita a los agentes/IA de Ciszu Network (opencode, Kilo,
Freebuff, etc.) a usar los **modelos de Google Gemini**. No es una website: es la **capa de
permisos de modelos LLM** dentro del ecosistema.

- Proyecto GCP: `gen-lang-client-0885445248` (nombre visual *CiszuAI*, sin billing).
- API principal: Generative Language (`generativelanguage.googleapis.com`).
- Documentación viva: `docs/documentation/PROJECT_STATE.md` · `PROJECT_HISTORY.md`.
- Documentación de modelos/facturación (global): `MODELS_LLM_SYSTEM.md` y `MODELS_SKILLS_SYSTEM.md` en `projects/ciszu/docs/documentation/`.
