PREGUNTAS FRECUENTES / FREQUENTLY ASKED QUESTIONS

[ESPAÑOL]

SOBRE CISZU NETWORK

1. ¿Qué es Ciszu Network?
   Es una iniciativa independiente que agrupa proyectos de software, entretenimiento y comunidad,
   fundada por Ciszuko Antony (Francisco Garcia) en Caracas, Venezuela.

2. ¿Es una empresa?
   No, Ciszu Network no es una empresa registrada. Es un espacio de creación libre y comunidad.

3. ¿Qué proyectos conforman la red?
   CiszuNetwork Page (portal), Ciszuko Antony (portfolio), MuzicMania (juego de ritmo),
   CiszuBot (bot de Discord), CiszuGamens (comunidad gaming) y @ciszunetwork/cdn (assets).

SOBRE LOS PROYECTOS

4. ¿MuzicMania es gratuito?
   Sí, MuzicMania es completamente gratuito, tanto en su versión web como de escritorio.

5. ¿Cómo puedo descargar MuzicMania?
   Desde la página de descargas en muzicmania.vercel.app/download o usando el instalador de Windows.

6. ¿CiszuBot está disponible para mi servidor?
   El bot está en desarrollo. La landing page está activa pero el bot aún no está disponible públicamente.

7. ¿Cómo me uno a CiszuGamens?
   Únete al servidor de Discord de Ciszu Network y accede a la sección de gaming.

SOBRE DOCUMENTACIÓN

8. ¿En qué formatos está disponible la documentación?
   TXT (texto plano), MD (markdown), DOCX (Word) y PDF (documento portátil).

9. ¿Dónde puedo descargar la documentación?
   En la carpeta public/docs/ de cada website, o directamente en docs/ del repositorio.

10. ¿Los documentos están en español o inglés?
    Todos los documentos son bilingües (ES/EN).

SOBRE DESARROLLO

11. ¿El código es open source?
    Sí, todo el código se distribuye bajo licencia MIT.

12. ¿Dónde está el repositorio?
    En GitHub, bajo la organización Ciszu Network.

13. ¿Qué stack tecnológico usan?
    Next.js 15 + TypeScript + Tailwind CSS v4 + Supabase + Tauri 2 + pnpm + Turborepo + Vercel.

[ENGLISH]

ABOUT CISZU NETWORK

1. What is Ciszu Network?
   An independent initiative that brings together software, entertainment, and community projects,
   founded by Ciszuko Antony (Francisco Garcia) in Caracas, Venezuela.

2. Is it a company?
   No, Ciszu Network is not a registered company. It is a space for free creation and community.

3. What projects make up the network?
   CiszuNetwork Page (portal), Ciszuko Antony (portfolio), MuzicMania (rhythm game),
   CiszuBot (Discord bot), CiszuGamens (gaming community), and @ciszunetwork/cdn (assets).

ABOUT PROJECTS

4. Is MuzicMania free?
   Yes, MuzicMania is completely free, both in its web and desktop versions.

5. How can I download MuzicMania?
   From the downloads page at muzicmania.vercel.app/download or using the Windows installer.

6. Is CiszuBot available for my server?
   The bot is in development. The landing page is active but the bot is not yet publicly available.

7. How do I join CiszuGamens?
   Join the Ciszu Network Discord server and access the gaming section.

ABOUT DOCUMENTATION

8. What formats is the documentation available in?
   TXT (plain text), MD (markdown), DOCX (Word), and PDF (portable document).

9. Where can I download the documentation?
   In the public/docs/ folder of each website, or directly in docs/ of the repository.

10. Are documents in Spanish or English?
    All documents are bilingual (ES/EN).

ABOUT DEVELOPMENT

11. Is the code open source?
    Yes, all code is distributed under the MIT license.

12. Where is the repository?
    On GitHub, under the Ciszu Network organization.

13. What tech stack do you use?
    Next.js 15 + TypeScript + Tailwind CSS v4 + Supabase + Tauri 2 + pnpm + Turborepo + Vercel.
