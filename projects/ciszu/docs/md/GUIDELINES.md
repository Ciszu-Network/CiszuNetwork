DIRECTRICES / GUIDELINES

[ESPAÑOL]

DIRECTRICES DE DESARROLLO
- Todo el código debe seguir las convenciones del proyecto (TypeScript estricto,
  Tailwind CSS v4, ESLint)
- Los commits deben ser en español, descriptivos y de una línea
- No se debe commitear archivos grandes ni credenciales
- Usar pnpm como gestor de paquetes

DIRECTRICES DE DOCUMENTACIÓN
- Los docs/ de cada proyecto deben mantener la estructura estándar
- Los documentation/ son para consumo de IA, no para usuarios finales
- Los documentos públicos (md, txt, docx, pdf) deben ser bilingües (ES/EN)
- MuzicMania es el proyecto referencia para la estructura

DIRECTRICES DE COMUNIDAD
- Respetar a todos los miembros de la comunidad
- No realizar spam, acoso ni compartir contenido inapropiado
- Seguir las reglas específicas de cada proyecto/servidor
