## 3. Protocolo de publicación cruzada (Cross-posting)

### 3.1 Matriz de prioridad

| Contenido | Primario | Secundario | Terciario | Automatización |
|---|---|---|---|---|
| **Lanzamiento mayor** | Blog (Ciszu Network) → Twitter/X Corp → Discord All → LinkedIn | YouTube (CEO) → TikTok/Reels → Instagram | Twitter/X Proyecto → Discord Proyecto | Manual (CEO) |
| **Update / Patch** | Twitter/X Proyecto → Discord Proyecto → GitHub Releases | — | — | Semi-auto (script) |
| **Contenido visual (Art/Design)** | Instagram (CEO) → Twitter/X Corp + Personal | ArtStation/Behance | TikTok/Reels/Shorts | Manual (CEO) |
| **Devlog / Tutorial** | YouTube (CEO) → Twitter/X Personal + Corp | Blog técnico (Ciszu Network) | TikTok/Reels clips | Manual (CEO) |
| **Evento / Torneo** | Discord Comunidad → Twitter/X Proyecto → TikTok highlights | — | YouTube highlights post-evento | Mods + Auto-clips |
| **Anuncio corporativo** | Twitter/X Corp → Discord All → Email newsletter | Twitter/X Personal (retweet) | — | Manual (CEO) |

### 3.2 Checklist pre-publicación

- [ ] Copy revisado (ortografía, tono, links válidos)
- [ ] Assets optimizados (WebP/AVIF, < 1MB, alt text)
- [ ] Hashtags relevantes (3-5 máx): `#CiszuNetwork #Gamedev #IndieDev #Valorant #RhythmGame`
- [ ] Menciones correctas (`@CiszuNetwork`, `@CiszukoAntony`, `@MuzicManiaGame`, `@CiszuBot`)
- [ ] UTM params en links web (`?utm_source=twitter&utm_medium=social&utm_campaign=launch_v2`)
- [ ] Programado en hora pico (VE: 19:00-21:00 / UTC-4)

## 5. Protocolos de crisis en redes

| Nivel | Trigger | Acción | Responsable | Comunicación |
|---|---|---|---|---|
| **1 - Menor** | Typo, link roto, métrica baja | Corregir + re-publicar si necesario | CM | Interno |
| **2 - Moderado** | Bug visible usuarios, queja viral | Hotfix + hilo explicativo + fix ETA | Dev Lead + CEO | Público (transparente) |
| **3 - Crítico** | Brecha seguridad, downtime > 1h, controversia mayor | War room + comunicado oficial + post-mortem | CEO + Security | Público + Email stakeholders |
