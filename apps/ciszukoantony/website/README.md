# Ciszuko Antony — Portfolio

Sitio web oficial de **Ciszuko Antony**, CEO & Fundador de **Ciszuko Network**.

## Stack

- **Next.js 15** — React framework
- **Tailwind CSS v4** — Estilos utilitarios
- **Framer Motion** — Animaciones
- **TypeScript** — Tipado estático
- **Vercel** — Hosting & deploy

## Desarrollo

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
```
