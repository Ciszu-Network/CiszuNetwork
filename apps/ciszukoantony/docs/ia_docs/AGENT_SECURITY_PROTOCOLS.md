# 🛡️ Protocolos de Seguridad — Ciszuko Antony Portfolio

## 1. Datos Personales
- Los datos de contacto reales (email, teléfono) NUNCA deben exponerse en código.
- Usar variables de entorno para datos sensibles.

## 2. Protección de Assets
- Las imágenes y multimedia se sirven desde Supabase Storage.
- No incluir assets grandes en el repositorio.

## 3. Formularios
- Validar datos del lado del servidor.
- Proteger contra spam con rate limiting.
