# MuzicMania — Guía de Licencias

## Tipos de Licencia

1. All Rights Reserved — Propiedad de CiszukoAntony Music
2. Creative Commons CC-BY — Libre con atribución
3. Creative Commons CC-BY-NC — Libre uso no comercial con atribución
4. Creative Commons CC0 — Dominio público

## Para Nuevos Lanzamientos

1. Decide el tipo de licencia
2. Genera el archivo license.txt con la info básica
3. Genera el archivo license.md con formato markdown
4. Incrusta el copyright en los metadatos del audio
