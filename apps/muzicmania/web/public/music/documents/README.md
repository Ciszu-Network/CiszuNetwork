# MuzicMania — Music Documents

This folder contains documentation, licenses, and metadata for all MuzicMania music assets.

## Structure

- /albums/ — Full albums with multiple tracks
- /singles/ — Individual track releases
- /remix/ — Remixed tracks
- /documents/ — This folder (templates & guides)

## Adding New Music

1. Create a folder under the appropriate directory
2. Include: audio.mp3, audio.ogg, cover.png, license.{txt,md}, about_readme.{txt,md}
3. Update TRACKS_DATA in src/data/tracks.ts
4. Create a level config in src/data/levels/
