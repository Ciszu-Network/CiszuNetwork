SOBRE CISZU NETWORK / ABOUT CISZU NETWORK

[ESPAÑOL]

Ciszu Network es una iniciativa independiente y multipropósito que reúne proyectos de software, entretenimiento y comunidad. Fundada y operada por Ciszuko Antony (Francisco Garcia) desde Caracas, Venezuela, la red abarca desde aplicaciones web modernas hasta bots de Discord, pasando por videojuegos rítmicos, herramientas de automatización, sistemas de gestión de assets y comunidades gaming.

VISIÓN Y FILOSOFÍA
Nuestra visión es crear un ecosistema digital cohesionado donde cada proyecto comparta estándares de calidad, diseño y documentación. No aspiramos a ser una empresa corporativa, sino un espacio de creación libre donde el código, el arte y la comunidad convergen bajo estándares profesionales.

Principios fundamentales:
- Código abierto y transparente
- Documentación completa en múltiples formatos
- Estética neón y cyberpunk como identidad visual
- Experiencia de usuario pulida y profesional
- Automatización de procesos de build y despliegue
- Estándares de seguridad en todo el código

PROYECTOS ACTIVOS

1. CiszuNetwork Page (apps/website)
   Portal principal de la red. Next.js 15 con App Router, TypeScript estricto y Tailwind CSS v4.
   Sirve como centro de información sobre todos los proyectos de la red.
   Estado: ✅ Activo

2. Ciszuko Antony Portfolio (apps/ciszukoantony/website)
   Portfolio personal de Francisco Garcia. Muestra proyectos, habilidades y experiencia.
   Next.js 15 con diseño responsivo y paleta neon.
   Estado: ✅ Activo

3. MuzicMania (apps/muzicmania)
   Juego musical con estética neón y cyberpunk. Plataforma de ritmo con modos web y escritorio.
   - Versión web: Next.js 15 + Canvas API para el motor de juego
   - Versión escritorio: Tauri 2 (Rust + WebView2) para Windows
   - Instaladores NSIS para Windows 10/11
   - Motor de juego con detección de ritmo, combos y puntuaciones
   - Sistema de iconos profesional con 5,194 SVGs
   Estado: ✅ Activo (en desarrollo continuo)

4. CiszuBot (apps/ciszubot)
   Bot de Discord multipropósito con landing page informativa.
   - Website: Next.js 15 con información de comandos y características
   - Bot: Discord.js v14 con comandos slash
   - Documentación del servidor Shigamens incluida
   Estado: ⚠️ Website activo, bot en desarrollo

5. CiszuGamens (ciszugamens/)
   Comunidad gaming oficial de Ciszu Network. Espacio para torneos, eventos y socialización.
   - Servidor de Discord con canales temáticos por género
   - Sistema de moderación y staff
   - Torneos regulares de diversos videojuegos
   Estado: ✅ Comunidad activa

6. @ciszunetwork/cdn (packages/cdn)
   Sistema compartido de resolución de assets e iconos.
   - resolveIcon(name, style, format) para iconos SVG
   - assetResolver.resolve(path) para assets multimedia
   - Integración con Supabase Storage
   Estado: ✅ Activo

ECOSISTEMA TÉCNICO
- Monorepo: pnpm workspaces + Turborepo
- Frontend: Next.js 15 + React 19 + TypeScript 6 + Tailwind CSS v4
- Backend: Supabase (PostgreSQL + Auth + Storage)
- Desktop: Tauri 2 (Rust)
- Bots: Discord.js v14
- CI/CD: GitHub Actions + Vercel
- Documentación: txt > md > docx > pdf (pipeline automatizado)
- CDN: Supabase Storage (bucket ciszu-assets)

ESTÁNDARES DE DOCUMENTACIÓN
Cada proyecto mantiene documentación en 4 formatos:
- TXT: Fuente de verdad en texto plano
- MD: Markdown para visualización web
- DOCX: Microsoft Word para edición
- PDF: Documento portátil para distribución

Además, cada proyecto tiene ia_docs/ con documentación técnica para agentes de IA,
siguiendo una estructura estandarizada de 12-19 archivos.
