 CISZU NETWORK - CONSOLE DEV DEBUGGING (GUI) DE USO
 test/website/debug/dev_console.ps1  -  v2.4.0
=====================================================================

QUE HACE
--------
- Encender / reiniciar / detener cada webapp (Next.js next dev con puerto fijo).
- Operativas con menu de seleccion MULTIPLE y webs marcadas por defecto.
- Estado de puertos y apertura de cada web en el navegador.
- Logs a tiempo real (Get-Content -Tail -Wait) SOLO de webs encendidas.
- CDN local (offline :8788): server estatico del monorepo como
  NEXT_PUBLIC_CDN_URL, arranca al encender webs y se MANTIENE activo al salir.
- Herramientas extra (limpiar logs, procesos, puertos, navegador, git,
  versiones, disco, estado/reinicio del CDN local, etc).
- Ayuda, creditos y version integrados.

PUERTOS FIJOS (nomenclatura del monorepo)
-----------------------------------------
  Ciszu Network   ciszunetwork-website   3000  projects/ciszu/website
  Ciszuko Antony  ciszukoantony-website   3001  projects/ciszukoantony/website
  CiszuBot        ciszubot-website       3002  projects/ciszubot/website
  MuzicMania      muzicmania-website     3003  projects/muzicmania/website

COMO ABRIRLA
------------
  1) Desde cualquier PowerShell (comando del perfil):
        devcon

  2) Directo desde el repositorio (raiz E:\Ciszu Network):
        powershell -NoProfile -ExecutionPolicy Bypass -File test\website\debug\dev_console.ps1

  3) Desde la raiz del monorepo:
        pnpm dev:console

USO DEL MENU DE SELECCION MULTIPLE
----------------------------------
  Flecha arriba (Up)       = moverse hacia arriba
  Flecha abajo (Down)      = moverse hacia abajo
  Espacio                  = marcar / desmarcar la web resaltada
  A                        = marcar TODAS las webs
  NUMEROS 1-9 (0 = 10)     = saltar directo al indice de la opcion
  Enter                    = PROCEDER (ejecutar la operacion en las webs marcadas)
  N                        = NO PROCEDER (cancelar, vuelve al menu sin aplicar)
  Q o Esc                  = ABORTAR (cierra la consola; las webs siguen activas)

  Las webs vienen MARCADAS POR DEFECTO en cada operativa.
  Opciones y webs usan EMOJIS (estilo neon del perfil):
    "▸ [1] 🚀 Encender webs"   "  [☑] 🎨 Ciszuko Antony port 3001"
  El selector se resalta en amarillo; los rojos son solo para errores.
  Estados: 🟢 ENCENDIDA / 🟡 ENCENDIENDO... / ⚫ DETENIDA

FLUJO TIPICO
------------
  1. Abrir la consola (devcon).
  2. Menu principal: Elige una OPERATIVA (Encender / Reiniciar / Detener).
  3. Se abre el menu de seleccion con TODAS marcadas; desmarca con Espacio.
  4. Enter para PROCEDER (o N para cancelar, Q/Esc para abortar).
  5. La consola ESPERA a que cada web compila (mostrando spinner) y avisa
     cuando queda lista en http://localhost:3000 ... 3003.
  6. "Estado" permite consultar las webs que elijas (una, varias o todas).
  7. "Logs en tiempo real" abre el log (next dev) de UNA web ENCENDIDA por vez.
  8. "Salir (Ctrl+C)" cierra SOLO la consola; las webs Y el CDN local
     siguen activos en sus puertos (usa pnpm dev:stop para detenerlas).

CDN LOCAL (OFFLINE)
-------------------
  Las webs resuelven assets con @ciszunetwork/cdn. En local,
  NEXT_PUBLIC_CDN_URL = http://localhost:8788 (server estatico, scripts/
  serve-cdn.js) que sirve el monorepo 1:1 como Supabase Storage, asi los
  logos (projects/*/content/logos), fotos (shared/images) y medios cargan
  desde el disco SIN INTERNET.
  - Arranca solo al encender la primera web (Ensure-CdnServe).
  - PID/log: test/website/debug/local-logs/cdn-serve.pid / cdn-serve.log.
  - No se detiene al Salir (los servidores se mantienen activos a proposito).
    Reinicio manual: Herramientas > "Reiniciar CDN local".
  - Manual: pnpm cdn:serve.
  - Si logos no cargan: Herramientas > "Estado CDN local" (8788).

MODO CLI (sin menu, para automatizacion)
---------------------------------------
  Estado de todas las webs:
      powershell -File test\website\debug\dev_console.ps1 -Action status

  Encender / reiniciar / detener una web (network | antony | ciszubot | muzic):
      dev_console.ps1 -Action start   -Web network
      dev_console.ps1 -Action restart -Web ciszubot
      dev_console.ps1 -Action stop    -Web muzic

  Ver log en vivo de una web (ventana separada):
      dev_console.ps1 -Action log -Web network

  Comandos cortos del perfil PowerShell:
      devweb / devantony / devbotweb / devmuzic   encender cada web
      devall  encender todas | devstop detener todas
      devstatus  estado rapido de puertos
      devlog <web>  log en vivo

PRUEBAS (sin Pester)
--------------------
  SelfTest interno (determinista, sin interactividad):
      powershell -File test\website\debug\dev_console.ps1 -SelfTest

  Runner completo (sintaxis + BOM + SelfTest + Demo + CLI status):
      powershell -File test\website\debug\dev_console.tests.ps1

LOGS
----
  Ubicacion: test/website/debug/local-logs/<key>.log  (gitignored)
  Claves: network, antony, ciszubot, muzic  (errores en <key>.log.err)
  En vivo: ventana PowerShell separada con Get-Content -Tail 80 -Wait.
  Cerrar la ventana del log no afecta al TUI ni a los procesos Next dev.
  OJO: solo las webs ENCENDIDAS tienen log en tiempo real; si una web
  esta detenida, el log no se ofrece (evita logs viejos sin sentido).

RESOLUCION DE PROBLEMAS
-----------------------
  - Puerto ocupado: revisar con devstatus, detener la web o usar
    Herramientas > "Ver que puertos 3000-3003 estan ocupados".
  - Web no responde a los 5s: el compilador de Next sigue trabajando;
    esperar y verificar de nuevo en Estado de puertos o ver el log.
  - Logs acumulados: Herramientas > "Limpiar logs".
  - pnpm no encontrado: la consola hereda el entorno de la PowerShell;
    abrirla desde una sesion con pnpm configurado.
  - "Salir" no cierra la consola: desde v2.4.0 Salir/Ctrl+C cierran SOLO la
    consola y las webs siguen activas (por diseno). Para detener las webs:
    menu "Detener webs" o `pnpm dev:stop`. Si la consola aun no cierra, abre
    con -SelfTest para verificar el estado del script.
